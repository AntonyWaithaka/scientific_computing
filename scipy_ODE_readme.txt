New assumptions
Transmission rate β lowered from 0.4 to 0.2.

Same recovery rate γ = 0.15, N = 10000, seed 10 infections.

Input data
β = 0.2, γ = 0.15, N = 10000, I0 = 10.

Output
text
Peak infected: 1701
Peak time:     37.2 days
Final recovered: 6666
Final susceptible: 3334
Interpretation
Halving β reduces R0 from ~2.67 to ~1.33. Peak infections drop from ~3140 to ~1700 and the epidemic ends later but with far fewer total cases. This is the quantitative effect of social distancing — the same model with a smaller β flattens the curve.
